# Comparative Analysis of Machine Learning Models for Product Profitability Prediction
This project performs a comparative analysis of various machine learning models to predict product profitability.

### Overview
This project analyzes and compares the performance of a various regression models to predict product profitablility. By leveraging Python's data science ecosystem. The workflow includes:
* Data Extraction: Extracting data from multiple source (Excel and  CSV)
* Merging data from multiple sources (Excel and CSV) into unified dataset
* Engineering new features and selecting relevant ones
* Training and evaluating machine learning models
* Determining the most suitable model based on evaluation metrics

The results highlight that **Linear Regression** outperforms other models, providinga higly accurate and reliable prediction of product profitability. 

### Features
 **Data Extraction and Preprocessing**: Combining datasets from Excel and CSV into a unified format
 **Feature Engineering**: Creating new features and selecting relevant ones for model training
 **Model Comparison**: Evaluating and comparing the performance of:
  * Linear Regression
  * Random Forest Regression
  * Ridge Regression
  * Decision Tree Regression
  * Gradient Boosting Regression
**Evaluation Metrics**:
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* Mean Absolute Error (MAE)
* R-squared Score

### Tools and Technologies
